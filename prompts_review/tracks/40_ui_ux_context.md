# Track D — UI/UX, Comments, Workshop, and Design Context

Compare available UX screenshots or design exports with the documented
controls, labels, visibility, states, responsive/tablet behavior, and
accessibility requirements in scope. Image attachments are reviewed by the
dedicated `review-vision` agent using visual inspection only; OCR is not used.
Review only comments and workshop decisions explicitly included in the local
snapshot.

Apply source authority from `config/review/source_authority.yaml`. If a design or image is not supplied or cannot be interpreted, report that
limitation. Static visual evidence cannot prove runtime interaction, API
behavior, permissions, keyboard behavior, screen-reader behavior, or
responsive behavior.
Do not infer visual details from a filename or placeholder.
