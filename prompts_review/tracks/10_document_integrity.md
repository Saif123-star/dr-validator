# Track A — Document and Attachment Integrity

Run deterministic checks first. Review DR section structure, duplicated or
missing sections, broken local references, missing or unexpected attachments,
workbook sheet presence, workbook structure, and table/header consistency.
Check available Markdown against its corresponding published-page snapshot
only when both are supplied.

Do not infer image contents or use semantic judgment for checks that can be
computed. Record unsupported formats or inaccessible evidence as unavailable,
not as defects. Findings must cite source IDs and exact evidence.
